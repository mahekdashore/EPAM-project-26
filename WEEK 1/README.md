# XYZ Bank Customer Coupon Portal

A beginner-friendly JavaScript project developed as part of the EPAM Project Development Program.

## About the Project

The XYZ Bank Customer Coupon Portal is a dynamic web page that allows customers to validate their Customer ID and generate a unique Diwali coupon.

The project demonstrates fundamental JavaScript concepts including DOM manipulation, event handling, functions, input validation, and random number generation.

## Features

- Welcome message using mouseover event
- Customer registration interaction
- Customer ID validation
- Empty input validation
- Diwali coupon generation
- Random 4-digit coupon number
- Dynamic webpage styling using JavaScript
- Interactive buttons and messages

## Technologies Used

- HTML5
- JavaScript
- DOM Manipulation
- JavaScript Event Listeners

How to Run?
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server or directly in a web browser.
4. Enter a Customer ID.
5. Click Validate Customer.
6. Generate your Diwali coupon.
